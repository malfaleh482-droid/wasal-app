# وصال — تطبيق العائلة

تطبيق ويب عربي متجاوب يعمل على Node.js وSQLite محليًا، دون مكتبات طرف ثالث أو خدمات مدفوعة. روعي في الهوية الكحلي والذهبي وتوزيع الهاتف المكتبي في المرجع المرئي المرفق. التطبيق لا ينشئ أعضاء وهميين.

## التشغيل

يتطلب Node.js 22.5 أو أحدث لدعم `node:sqlite`.

```powershell
npm run setup-admin
npm start
```

التسجيل العام يطلب اسم المستخدم ورقم الجوال والاسم الرباعي (أربعة مقاطع) والكنية وكلمة المرور وتأكيدها. يُحفظ الطلب بحالة «بانتظار التفعيل» ولا يستطيع العضو تسجيل الدخول حتى يوافق المدير العام. بعد التفعيل يكون اسم المستخدم هو معرّف الدخول؛ البريد الإلكتروني اختياري.

أدخل بريد المدير العام واسمه وكلمة مرور من اختيارك، ثم افتح `http://127.0.0.1:3000`. الخادم يربط نفسه بعنوان loopback افتراضيًا. لا تفتحه على شبكة خارجية قبل إعداد HTTPS ونسخ احتياطي لمفتاح التشفير. يمكن ضبط `HOST` و`PORT`، ومسار قاعدة البيانات `WASAL_DB_PATH`، ومفتاح النسخ الاحتياطي `WASAL_BACKUP_KEY` (32 بايت بصيغة Base64).

## البيانات والخصوصية

- تحفظ قاعدة البيانات في `data/wasal.sqlite`. لا توجد بيانات أعضاء تجريبية في النسخة.
- شجرة العائلة الأصلية محفوظة في `public/assets/family-tree.pdf`، ويقدمها الخادم بعد التحقق من الجلسة وصلاحية `tree.read`.
- كلمات المرور تُجزأ بـPBKDF2-SHA256 مع salt فريد؛ لا تُعاد كلمات المرور أو تحفظ في السجلات.
- جلسات الدخول تستخدم cookie من نوع HttpOnly وSameSite=Strict. عند `NODE_ENV=production` يضاف Secure.
- النسخ تُشفّر بـAES-256-GCM؛ يُنشأ مفتاح محلي عند أول نسخة. فقد المفتاح يعني عدم إمكان فك النسخ، لذلك احتفظ بنسخة آمنة منه خارج الجهاز.
- ملفات التصدير والنسخ تحفظ خارج مجلد الويب ولا تقدم إلا بعد تفويض الخادم.

## ما يعمل في هذه المرحلة

- تسجيل دخول، أدوار أساسية، جلسات، سجل محاولات الدخول، وقفل الحساب بعد خمس محاولات فاشلة.
- صفحة رئيسية وأقسام الشجرة والأعضاء والأخبار والتعاميم والمناسبات والإشعارات والملف الشخصي والإعدادات.
- التحقق من الصلاحية في واجهة API، وفصل بيانات المدير العام ومساعده والعضو.
- نشر الأخبار والتعاميم والمناسبات بحسب الصلاحية، ومراجعة طلبات تعديل الملف مع نافذة تعديل 48 ساعة.
- موافقة المدير على العضويات المعلقة وطلبات حذف الحساب؛ موافقة الحذف تعطل الحساب وتزيل بيانات الملف الشخصية مع إبقاء سجل تدقيقي منقح.
- مركز الإشعارات الفردي مع القراءة والحذف، وبلاغ أمني، وعرض سجل الإدارة ومحاولات الدخول والجلسات.
- استعادة كلمة المرور برمز بريد من 6 أرقام، تنتهي صلاحيته بعد 10 دقائق ويُستخدم مرة واحدة، مع تحديد محاولات الإرسال والتحقق وإنهاء الجلسات بعد التغيير.
- حظر الأجهزة للمدير العام ورفع الحظر للمساعدين، وحظر IP ورفعه وفق الأدوار.
- إنشاء النسخ المشفرة وتنزيلها واستعادتها بعد فحص سلامة القاعدة، مع نسخة أمان قبل الاستعادة. النسخ الدورية كل 183 يومًا وتنظيف النسخ المنتهية يعملان ما دام الخادم يعمل.
- تصدير CSV متوافق مع Excel وصفحة طباعة لحفظ PDF، مع السجل والتنزيل والتمديد والحذف، وإشعار قبل انتهاء الملف بسبعة أيام.
- شجرة PDF مرفقة كما هي؛ لم تُستخرج الأسماء والعلاقات إلى بيانات منظمة لأن الملف صورة كبيرة مزدحمة تحتاج مراجعة بشرية.

## ما يحتاج استكمالًا قبل اعتماد التشغيل الفعلي

- واجهات إدارة تعيينات المسؤولين، سجل المناصب، وإيقاف مسؤول القسم بجدولة بدء/انتهاء تلقائية.
- واجهة مراجعة البلاغات الأمنية وفك قفل الحساب قبل انتهاء 24 ساعة.
- إرسال الاستعادة فعليًا يتطلب إعداد SMTP في ملف `.env` بالاعتماد على القالب `.env.example`. لحساب Outlook.com يستخدم وصال `smtp-mail.outlook.com:587` مع STARTTLS وOAuth2؛ لا تضع كلمة مرور الحساب في SMTP. يلزم تسجيل تطبيق Microsoft يدعم الحسابات الشخصية وإضافة إذن SMTP.Send المفوض، ثم وضع Application (client) ID في `.env` وتشغيل `npm run connect-outlook` لإكمال التفويض وحفظ رمز التحديث محليًا. بعد ذلك أعد تشغيل الخادم.
- ملف XLSX أصلي، وتقارير أداء نصف سنوية قابلة للمقارنة.
- تشفير بيانات SQLite الحساسة أثناء التخزين، وإعداد TLS للاستضافة، وتوسيع اختبارات الأمان والتشغيل واختبار واجهة المتصفح على أجهزة وأحجام متعددة.
- سياسة صلاحيات البيانات الحساسة، مدد حظر IP، وسياسات الاحتفاظ بالسجلات ما زالت تحتاج اعتمادًا.

## الاختبارات

```powershell
node --check server.mjs
node --check public/app.js
node scripts/smoke-test.mjs
```

اختبار الدخان ينشئ قاعدة منفصلة مؤقتة ويحذفها بعد التحقق من تسجيل الدخول، وعزل الأدوار، وحماية الشجرة، والتصدير، والنسخ والاستعادة.

## ملفات هذا المستودع

ملف Wasal_Source.zip يحوي مصدر التطبيق بعد استبعاد قاعدة البيانات والأسرار وشجرة العائلة الأصلية. بعد فك الضغط، أضف ملف الشجرة الذي تملكه إلى public/assets/family-tree.pdf قبل التشغيل إذا أردت عرضها. عيّن إعدادات البريد محليًا في .env باستخدام قالب .env.example، ولا ترفع بيانات الدخول أو قاعدة البيانات إلى GitHub.
